# HU-02 · Buscar y seleccionar a un empleado

Como administrador, quiero buscar por nombre para encontrar al empleado cuya asistencia debo marcar o consultar.

**Actor** · [[Rol-Administrador]].

## Datos de búsqueda y selección

- **Nombres o apellidos.** La búsqueda ignora mayúsculas, minúsculas y tildes.
- **Nombre y DNI.** Aparecen en cada resultado. El DNI identifica de forma única al empleado que se selecciona.

## Flujo principal

1. El administrador abre **Asistencia** para marcar o **Historial** para consultar.
2. Escribe parte de los nombres o apellidos del empleado.
3. La aplicación muestra las coincidencias con el nombre y el DNI de cada empleado. En **Asistencia**, las muestra en un desplegable desde la segunda letra.
4. El administrador verifica el DNI cuando hay nombres iguales y selecciona el resultado correspondiente.
5. En **Asistencia**, los controles de marcación aparecen en el mismo panel y las nuevas marcaciones se asocian al DNI seleccionado. En **Historial**, la aplicación muestra las marcaciones de ese DNI.

## Criterios de aceptación

### CA-01 · Buscar desde un celular

Dado que hay empleados registrados, cuando el administrador busca un nombre desde un celular, entonces puede ver el nombre y el DNI de cada coincidencia y seleccionar un resultado con controles táctiles, sin desplazamiento horizontal.

### CA-02 · Empleados con el mismo nombre

Dado que dos empleados comparten el nombre y tienen DNI distintos, cuando el administrador busca ese nombre, entonces la aplicación muestra ambos registros y permite seleccionar a cada empleado por separado.

### CA-03 · Consulta o marcación del empleado seleccionado

Dado que el administrador selecciona a un empleado entre dos personas con el mismo nombre, cuando consulta el historial o registra una marcación válida, entonces la aplicación usa el DNI elegido para mostrar las marcaciones correspondientes o guardar el nuevo movimiento.

### CA-04 · Búsqueda sin coincidencias

Dado que ningún empleado registrado coincide con el nombre buscado, cuando se muestran los resultados, entonces la aplicación informa que no encontró coincidencias y permite cambiar el nombre de búsqueda.
